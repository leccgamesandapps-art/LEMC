# LEMC Mod List

## Official Mods

### LEMC (Core)
- **Status**: Locked / Required on every LE-MC-HOST server
- **Version**: 1.0.0 (planned)
- **Can be removed?**: No
- **Purpose**:
  - Links the Minecraft server to the LE-MC-HOST website
  - Provides the **LEMC Config Item** that opens Server Config UI
  - Keeps Server Config and LEMC Config Item synchronized
  - Enforces ownership by Xbox Gamertag

### Relationship to Website

Every server created on [LE-MC-HOST](https://github.com/leccgamesandapps-art/LE-MC-HOST-SOURCE) automatically receives LEMC.

Changing settings in:
- Website → Server Config  → updates LEMC Config Item
- In-game → LEMC Config Item → updates Website Server Config

## Future Mods

Additional optional mods may be listed here in the future. LEMC will always remain the required core mod.
